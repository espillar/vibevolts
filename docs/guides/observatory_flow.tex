\section{Introduction}
This document traces the workflow for initializing, pointing, and recording observations using
ground-based observatories in VibeVolts. It outlines how observatories are built, how they track
targets, how exclusion and radiometry are evaluated, and how data is recorded.

\section{Building Observatories (Initialization)}
Ground-based observatories live inside their own component state while sharing unified accessors
with satellites:
\begin{itemize}
    \item \textbf{Allocation:} \texttt{add\_observatories()} in \texttt{observatories.py} takes
    latitudes, longitudes, and altitudes, populates \texttt{sim\_data.observatories}
    (\texttt{ObservatoriesState}), and allocates an initial \texttt{DetectorArray} at
    \texttt{sim\_data.observatories.detector}.
    \item \textbf{Configuration:} Users configure \texttt{sim\_data.observatories.detector} via
    \texttt{makeDetector()}, setting Field of View (FOV), integration time, and the Earth
    exclusion angle (\texttt{earthEx}), which acts as the minimum elevation angle above the local
    horizon.
    \item \textbf{Unified Aggregation:} No manual category tags are stored on the detector array.
    Instead, \texttt{sim\_data.detector} (\texttt{get\_all\_detectors()}),
    \texttt{get\_detector\_positions()}, \texttt{get\_detector\_categories()}, and
    \texttt{iter\_detector\_components()} aggregate across \texttt{satellites} and
    \texttt{observatories} dynamically.
\end{itemize}

\section{Pointing and Propagation}
\begin{itemize}
    \item \textbf{Propagation:} \texttt{propagate\_observatories()} transforms
    \texttt{astropy.coordinates.EarthLocation} coordinates to the GCRS frame as the Earth
    rotates, updating \texttt{sim\_data.observatories.position} and \texttt{velocity}.
    \item \textbf{Pointing:} Observatories are aimed by updating vectors in
    \texttt{sim\_data.observatories.detector.pointing}. In \texttt{all\_demos.py},
    \texttt{run\_observatory\_animation()} computes target lines-of-sight directly toward inertial
    targets, while \texttt{demo\_observatories\_only()} steps both satellites and observatories
    using \texttt{update\_detector\_pointing()}.
\end{itemize}

\section{Imaging and Radiometry}
When the simulation advances (e.g., via \texttt{nextIntegration()}), \texttt{scandetectors()} in
\texttt{scandetectors.py} performs the imaging calculations:
\begin{itemize}
    \item \textbf{Visibility \& Exclusion:} \texttt{exclusion()} and \texttt{scandetectors()}
    delegate to \texttt{check\_sim\_exclusions()} / \texttt{compute\_exclusions()} in
    \texttt{exclusion.py}. For ground observatories (\texttt{is\_ground = True}), the Earth-limb
    check is automatically replaced with the local-horizon check defined by \texttt{earthEx}.
    \item \textbf{Flux Calculation:} For visible targets, \texttt{lambertiansphere()} computes the
    apparent target brightness from the solar phase angle.
    \item \textbf{SNR Computation:} \texttt{scandetectors()} slices matching detectors via
    \texttt{hits = det.subset(sat\_hit\_idx)} and computes signal, background shot noise, and
    SNR across active hits.
\end{itemize}

\section{Recording Observations}
The results from \texttt{scandetectors()} are returned as a dictionary containing simulation time,
observer indices, target indices, signal, noise, and SNR.
\begin{itemize}
    \item \textbf{DataHandler:} The \texttt{DataHandler} class in \texttt{dataHandling.py} records
    step results via \texttt{add\_results()} and consolidates them into a Pandas DataFrame via
    \texttt{get\_dataframe()}.
    \item \textbf{Export:} Methods such as \texttt{save\_to\_csv()} and \texttt{save\_to\_parquet()}
    export observational datasets for analysis, and \texttt{plot\_gap\_times\_histogram()} plots
    revisit gaps.
\end{itemize}
